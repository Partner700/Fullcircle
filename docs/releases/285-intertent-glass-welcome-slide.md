# Release 285 — Championship welcome slide polish

The Cadet and Sentry welcome carousel now displays the current Journey championship fixture using a translucent glass surface, subtle background blur and a lighter artwork veil. The match number, group/series title and qualification status are omitted from the slide only. The date and compact countdown sit beneath the player matchup, with the Arena link above the card.

The Arena match cards, dates, live scores, player numbers, qualification and tournament rules are unchanged. No database changes are required.
