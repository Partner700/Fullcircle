# Release 282 — Individual championship match cards

Changes only the championship presentation: each fixture has an individual Arena-themed card with the scheduled local time, group and leg, tent symbols, teammates grouped into one side, member avatars (when available), match status, and entry/witness/share controls for ready rooms.

The existing tournament records, qualification checks, fixture dates, match rules, advancement, Supabase migration and Journey game backend are unchanged. Previously published fixtures use the new presentation without being recreated.

Build, TypeScript, Arena matchup, inter-tent integration and mobile resilience tests passed. Retain all prior release assets for existing installed clients.
